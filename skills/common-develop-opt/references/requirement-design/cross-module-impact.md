# 跨模块实现影响映射

## 快速规则

先确认当前任务的输入、revision、允许范围和停止条件。机器字段和参数边界统一见 [机器字段与状态边界](../core/machine-boundaries.md)。

## 详细规则

## 1. 适用范围
流程跨两个及以上模块、聚合或外部系统时，建立 `CMI-*` 映射和顺序 `CMSTEP-*`。业务语义仍引用稳定 `FLOW-*` 与 `STEP-*`，技术映射不能取代业务流程。

## 2. 每步内容
记录主责模块、参与模块、调用或事件契约、输入输出、幂等键、超时、重试、事务边界、部分失败、补偿和人工恢复。必须明确失败由谁发现、由谁恢复以及最终一致性条件。

## 3. 验证与 Review
至少覆盖成功路径、关键失败点、补偿失败和重复执行。CrossModuleIntegrationReviewAgent 核对顺序、契约、失败与补偿，并确认引用的 FLOW/STEP revision 当前有效。
