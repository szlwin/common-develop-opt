# 集成与跨模块测试

## 快速规则

先确认当前任务的输入、revision、允许范围和停止条件。机器字段和参数边界统一见 [机器字段与状态边界](../core/machine-boundaries.md)。

## 详细规则

## 1. 适用信号
数据库真实读写、跨模块调用、消息、外部系统、事务边界、最终一致性、补偿或 E2E 场景需要集成测试。单模块纯函数测试不默认加载本 Reference。

## 2. 覆盖要求
至少覆盖成功、超时、重复、乱序、部分失败、补偿失败和人工恢复；使用 trace/correlation ID 连接 CMI/CMSTEP、日志、消息和最终状态。

## 3. 环境限制
外部依赖不可用时明确记录未验证范围、替代证据和风险，不把 Mock 结果等同于真实集成通过。
