# 需求与设计

## 快速规则

先确认当前任务的输入、revision、允许范围和停止条件。机器字段和参数边界统一见 [机器字段与状态边界](core/machine-boundaries.md)。

## 详细规则

需求阶段确认目标、范围、验收语义、影响模块和未决决策。设计阶段读取当前实现事实，明确 Model、Flow、Impact、数据边界、兼容性和实现策略。

按需读取：`requirement-analysis-core.md`、`requirement-confirmation-core.md`、`requirement-acceptance.md`、`requirement-traceability.md`、`business-model.md`、`business-flow.md`、`design-core.md`、`cross-module-impact.md`、`implementation-plan.md`。
