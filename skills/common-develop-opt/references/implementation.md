# 实施与编码

## 快速规则

先确认当前任务的输入、revision、允许范围和停止条件。机器字段和参数边界统一见 [机器字段与状态边界](core/machine-boundaries.md)。

## 详细规则

编码前确认需求、Design、实施计划、允许文件、公共逻辑 Owner 和验证命令。伪代码只描述输入、规则、输出和异常边界；实际实现必须遵循项目代码契约。

按需读取正式的 `implementation-contract.md`、`implementation-plan.md`、`backend-code-reference.md`、`model-code-core.md` 和 `implementation-strategy.md`。
