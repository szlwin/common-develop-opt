## UL-AUTH-001 登录

| 属性 | 内容 |
| --- | --- |
| 统一名称 | 登录 |
| 英文/代码名称 | Sign In / Login |
| 领域 | 认证 |
| Owner | IAM / Authentication |
| 别名 | - |
| 首次引入 | V_1.0 |
| 状态 | ACTIVE |

### 定义

用户使用有效认证凭据完成身份验证，并建立当前认证会话的过程。

### 业务边界

登录只负责确认“当前访问者是谁”，不等同于判断该用户可以执行哪些业务操作。

### 不要混用

- 不要用“登录”表示“账号”。
- 不要用“登录”表示“授权”。

### 相关术语

- [账号]
- [认证]
- [授权]

### 使用示例

- 用户使用账号和密码登录系统。
