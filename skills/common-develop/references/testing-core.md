# 测试执行核心

## 1. 职责
Testing 验证当前 revision 的可观察行为，不替代 TDD、Code Review 或最终完成验证。TestAgent 先读取项目可执行入口和当前范围，只运行与任务相关且环境允许的测试。

## 2. 执行顺序
确认测试环境，执行最小相关测试，再按风险扩展到回归、前后端、架构规则或 E2E。失败立即停止推进，登记命令、退出码、报告和下一动作；修复后重新执行受影响范围。

## 3. 测试类型
相关范围测试、后端测试、前端测试、架构规则、覆盖率与复杂度、关联影响、跨模块实现、综合质量和完整回归按项目 Harness 配置选择。Skill 不硬编码框架、版本、阈值或报告路径。
