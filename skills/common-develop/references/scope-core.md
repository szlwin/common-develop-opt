# 研发任务范围最小边界

## 1. 默认范围
本 Skill 处理需求确认、需求分析、业务建模、设计、测试设计、实施计划、TDD、开发、独立 Review、测试、完成验证、长任务恢复和研发事实归档。

## 2. 默认排除
<!-- common-develop-invariant: GIT_PUSH_REQUIRES_CHECKPOINT -->
视觉稿与品牌设计、商业计划与运营策略、默认 Git push/merge、Release/部署/上线以及无项目基线的泛化问答不属于默认执行范围；其中 Git push 仅由显式 `wk -gp` 在 checkpoint 约束下例外授权。混合请求只执行研发部分，并明确列出排除项。

## 3. 范围门禁
执行前冻结目标、允许文件、禁止范围、输入 revision、验收语义和停止条件。发现范围外依赖时停止并重新做影响分析，不把附带重构伪装成必要修改。
