# Release Notes

Release notes for this Skill repository are kept here at the repository layer. The current installable bundle is `skills/common-develop-opt/` (the refactored package); `skills/common-develop/` is the previous pre-refactor bundle kept for reference only. Release notes and repository documentation are not copied into an Agent Skills installation.

Each release note should record:

- which bundle it applies to (`common-develop-opt`, or the legacy `common-develop` package);
- release summary and package version;
- changed Skill behavior, Contract, Reference, or CLI surface;
- migration or compatibility notes;
- known exceptions, deferred findings, and verification results.
